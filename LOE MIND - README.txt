DEADLOCK MODS
=============

EESTI KEELES
1. Paki zip lahti kausta, kuhu saad kirjutada (nt Dokumendid või Töölaud - MITTE Program Files).
2. Käivita "Deadlock Mods.cmd". Kui Windows hoiatab (SmartScreen): "More info" -> "Run anyway".
3. Kui üleval on punane rida "Mods are not enabled", vajuta "Enable mods" (mängu fail gameinfo.gi
   saab ühe rea juurde, originaal jääb kõrvale nimega gameinfo.gi.before_mods).
4. "+ Add mod": vali allalaaditud mod (.zip .rar .7z .vpk ...) või kleebi GameBanana link.
   Faile võid ka aknale lohistada.
5. Lülita modid sisse/välja ja vajuta "Save". Deadlock peab olema kinni.
Paremklõps modil: nimeta ümber, eemalda osi (häälread jne), allika link ja uuendused, kustuta.
"Check" vaatab modid üle, "Updates" otsib GameBananast uusi versioone.
Allalaaditud arhiivid lähevad kausta Downloads\Deadlock mods.

ENGLISH
1. Unzip to a folder you can write to (Documents or Desktop - NOT Program Files).
2. Run "Deadlock Mods.cmd". If Windows SmartScreen warns: "More info" -> "Run anyway".
3. If the top line says "Mods are not enabled", press "Enable mods" (adds one line to the game's
   gameinfo.gi; the original is kept as gameinfo.gi.before_mods).
4. "+ Add mod": pick a downloaded mod (.zip .rar .7z .vpk ...) or paste a GameBanana link. Dropping files works too.
5. Turn mods on/off and press "Save" (Deadlock must be closed).

Included tools: Python 3.13 embeddable (python.org, PSF license), Source2Viewer CLI
(ValveResourceFormat, MIT), 7-Zip (7-zip.org, LGPL, see tools\7zip\License.txt).
